# cloud-security-portfolio

An interactive, terminal-styled portfolio site — no framework, no build step,
just a single self-contained HTML file. Hosted live on Azure Blob Storage
static website hosting.

**Live site:** https://azureblob14.z19.web.core.windows.net/

## What it does

Visitors are greeted with a boot sequence styled after real Azure CLI output
(`az storage account show`), then an interactive terminal where clicking a
button or typing a command (`about`, `experience`, `skills`, `projects`,
`storage`, `security`, `contact`) reveals real content — no page reloads,
just JavaScript building the terminal output live.

The cloud and lock ASCII art aren't static images — they're generated by
rasterizing real geometry (overlapping circles for the cloud, a shackle +
body + keyhole for the lock) into a character grid, then filling that shape
with a continuous stream of relevant vocabulary (Azure Storage terms,
security terms) instead of plain block characters.

## Why this design

This site is itself Week 1 of an Azure Storage learning project — the
`storage` command explains Blob, Queue, File, and Table through a security
lens, directly tying into two other projects in this learning series:

- [Soc-alert-queue-demo](https://github.com/Cybertech2005/Soc-alert-queue-demo) — Azure Queue Storage
- [Procurement-card-audit-demo](https://github.com/Cybertech2005/Procurement-card-audit-demo) — Azure Table Storage

## Tech

Pure HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies,
no build step. Deployed by uploading `index.html` directly to a storage
account's `$web` container with static website hosting enabled.

## Deployment

1. Enable Static website hosting on an Azure Storage account, set index
   document to `index.html`
2. Upload `index.html` to the auto-created `$web` container
3. Visit the storage account's primary static website endpoint
